# 0005. Drizzle ORM over Prisma

- Status: accepted
- Date: 2026-10-30

## Context

The PRD allows Prisma or Drizzle on PostgreSQL. The API needs `ON CONFLICT` inserts, `SELECT ... FOR
UPDATE`, keyset pagination and a small container image.

## Decision

Drizzle with `node-postgres`.

- The schema is TypeScript, and its enums are built from the shared package's constants, so database
  enums, Zod enums and app labels cannot disagree.
- SQL features the idempotency and photo-limit logic rely on are expressed directly.
- Migrations are plain SQL files generated by `drizzle-kit`, reviewed in PRs and applied at container
  start under a Postgres advisory lock, so parallel tasks apply them once.
- No query engine binary, so the API image stays small.

## Consequences

- Less "magic" than Prisma (no generated client); relational loads are written as explicit queries.
- Money is stored as `bigint` cents and parsed to JS numbers; amounts are capped at R5,000,000, far
  below 2^53.
